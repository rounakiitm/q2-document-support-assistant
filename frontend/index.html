About

How this assistant meets the evaluation requirements.

What it does

Answers from your uploaded documents using hybrid retrieval (dense + BM25, RRF fusion). Every citation is string-matched against indexed chunks before the answer ships.

Memory behaviour

Per-session topic ledger, asked-question log with embedding + LLM repeat detection, and a rolling summary so older turns stay compact without losing context.

Honest fallbacks

Low retrieval scores trigger an explicit not-in-KB path. Optional web search is labelled separately and never cited as knowledge-base evidence.
